### 个人档案
- **身份：** 主教
- **起源：** 阿斯纶·伦塔普斯
- **主题：** 使命

红发，中等身高，表情看起来似乎闷闷不乐，手持的等身巨剑很显眼，认识她的人一眼就能认出她来。

### 背景故事

格涅辛出生于一个虔诚的宗教家庭中，父亲是小镇上一位朴实勤恳的神父，母亲则常年劳作于田地之间，持家守道。自幼在教堂庄严而宁静的氛围中成长，他每日目睹父亲诵读经文、抚慰信众的身影，那些充满慈悲与智慧的言语，渐渐在他心中埋下信仰的种子。十六岁那年，他毅然进入神学院，踏上追随神圣的道路。二十四岁时，他以优异的成绩从阿斯纶中央神学院毕业，随后前往首都伦塔普斯担任神官，在伦辛主教的指引下，始终怀抱善念，倾听并宽解百姓的疾苦。也是在这期间，他触及了“神明”的真相--神是由教众的信仰汇聚而成，神因人的信仰而能惠及苍生。神明的赐福于此时降下，蒙受赐福的格涅辛在弘扬真善的道路上行走的愈发坚定。

四十四岁那年，格涅辛踏上前往圣城迪图斯的朝圣之旅。途中经过一片古老遗迹时，他偶然发现了一把传说般的魔法剑——“时之匙”。正是这次相遇，令他意外掌握了操纵时间法术的能力。朝圣归来后，因德行与能力深受认可，他被擢升为伦塔普斯主教。五年后，格涅辛受命成为阿斯纶教皇，肩负起更重大的牧灵与引领之责。

就任后不久，战争的风暴在这片大陆上愈演愈烈，起因只是两国边境间小小的摩擦，在几年的僵持后突然席卷整个大陆。为了保证国家的安全，格涅辛率领举国骑士守卫边疆。经历了十余年的抵抗之后战争的烈度逐渐降低，但也早已民生凋敝，横尸片野，为了留下最后的文明火种，格涅辛与邻国的勇士集结，肩负起守护人类的重担，自伦塔普斯出发。

#### 符印
| 符印名称 | 符印效果                                                                                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 重生符印 | 带有此符印的生物可在其生命值即将降为0时销毁该符印。如果他这样做，其生命值将改为降至1点。                                                                                                              |
| 财富符印 | 当带有该符印的生物消耗1点物语点以援用一项特质或羁绊时，还将获得100金币。                                                                                                                     |
| 禁制符印 | 当你创建此符印时，选择一种行动类型：攻击、防御、推进目标、施法或技能。当带有此符印的生物执行所选行动时，他在执行该行动之前先失去5点生命值和5点精神值。若你大于等于20级，这两个数值提升至10点；若你大于等于40级，则改为提升至20点。                                     |
| 保护符印 | 当你创建此符印时，选择一种伤害类型：风系、雷系、暗系、土系、火系、冰系、光系或毒系。带有此符印的生物获得对所选伤害类型的抵抗相性。                                                                                          |
| 元素符印 | 当你创造此符印时，选择一种伤害类型：风系、雷系、暗系、土系、火系、冰系、光系或毒系。当带有该符印的生物对一个或多个生物造成伤害时，若你能看见带有此符印的生物，你可以消耗等同于对那些生物造成的总伤害量的三分之一的精神值（包括任何额外伤害）。如果你这样做，以此方式造成的所有伤害的类型变为创造此符印时选择的类型。 |
| 造物符印 | 带有该符印的生物如需在冲突中消耗物资点，可以改为销毁该符印，用以代替消耗物资点。                                                                                                                   |
