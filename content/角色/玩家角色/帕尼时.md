### 个人档案
- **身份：** 自由奔放的虔诚的怀着赤子之心的厨师
- **起源：** 自然之心教会
- **主题：** 希望

#### 背景故事

作为世界大战后第一个丰收秋天出生的孩子被封为圣子。

三岁，展现出对于烹饪的极度热爱，完美契合我教“细心地烹饪，如同细心地播种”。

六岁，熟读经文，对答如流，被海威斯特主教选中成为其教子。

十二岁，在教会学校中自己拆解播种机并加以改良，升入自然之理学院深入学习。

十八岁，以全A成绩完成全部科目，带着自己的并未设计完美的毕设《三栖全能猎人外骨骼装置》前往其他国家开始自己的求学之旅，争取在三年之内完成毕设。

### 职业

#### 美食家

> [!char-skill|5] 烹饪
> 当你在一处定居点休息时，你获得**技能等级**点食材。
> 作为一次行动，你可以组合2或3份食材来制作一份珍馐，并选择一个选项：将其效果施加给自己或一个你可见的盟友；或者，你执行一次装备武器的顺势攻击。这次攻击不造成伤害，但会将珍馐的效果施加给所有攻击命中的敌人。
> 你可以携带至多**10+技能等级×5**份食材，并且它们在使用前永不腐坏；如果你在创建角色时选择此技能，你开始游戏时拥有十份随机风味的食材。

> [!char-skill|1] 盐与胡椒
> 当你制作一份珍馐时，你可以消耗2点物资点：如果你这样做，将其中一份食材的风味改为你选择的另一种风味。

> [!char-skill|2] 旅行厨师
> 每次旅行掷骰后，如果你获得了烹饪技能，你获得**技能等级×2**份食材。

#### 造物使

> [!char-skill|1] 便携装置
> 当你首次习得此技能时，选择一种装置类型：炼金装置、注魔装置或魔导装置。你将获得相应的基础增益。
> 当你再次习得此技能时，从以下选项中选择一项：你获得新的装置类型的基础增益；或你在一项已有基础增益的装置类型上获得进阶增益；或你在一项已有进阶增益的装置类型上获得顶级增益。

#### 机师

> [!char-skill|1] 压缩科技
> 只要你的个人载具上没有人，你可以随时让它从游戏世界中消失。这是采用了什么样的魔法或科技？
> 如果你的个人载具不在游戏世界中，且你身处于一个足以容纳该载具的空间内，你可以执行消耗物资行动，消耗2点物资点使其出现在你附近，并且你可以进入该载具而无需消耗行动。

> [!char-skill|3] 个人载具
> 当你习得此技能时，你获得一部个人载具，你可以为这部载具选择一种框架和三个不同的模块。
> 每当你再次习得此技能时，你可以为你的载具额外选择两个模块。


### 职业资源
#### 载具

![[附件/帕尼时载具.png]]

帕尼时在自然之心教会的自然之理学院中研发的毕设，旨在设计一款水陆空三栖的全能外骨骼装备，方便美食猎人们狩猎野味。但由于中二病大爆发外观设计上朝着教会中记载的无头恶神——刑天靠拢。

载具框架：外骨骼

| 模块名称 | 原型     | 模块效果                                      | 启用状态 |
| ---- | ------ | ----------------------------------------- | ---- |
| 刑天戚  | 阔斧攻击模块 | **DEX+INS**+1/ HR+16 火焰伤害 针对野兽、植物造成额外5点伤害 |      |
| 兽皮衣  | 柔性装甲   | 防具模块 物防+2 魔防+1                            |      |
| 刑天干  | 符文盾牌   | 物防+2                                      |      |
| 浮空模块 | 飞行模块   |                                           |      |
| 元素抗性 | 雷元素抗性  |                                           | 未启用  |
| 强力锁定 |        | 命中鉴定获得+2修正                                |      |

**模块详细说明：**

- **刑天戚**：
    - **特性**：火焰伤害、命中+1修正、伤害+4、针对野兽、植物造成额外5点伤害
    - **描述**：效仿某个神秘传说中无头恶神创作的武器。为了更好地切割食材，斧柄采用特殊设计避免滑脱；斧背刻意加重方便断骨；斧刃做了内置加热，方便灭杀寄生虫做温度、口感刚刚好的刺身；两个斧面分别绘制了特殊不同的符文，用于处理各种野味
- **浮空模块**：
    - **特性**：此个人载具可以飞行，并且其移动距离变为×3。当你驾驶此个人载具时，你的近战攻击可以指定飞行生物为目标，而不具有飞行能力的角色无法对此个人载具中的任何生物进行近战攻击，除非攻击者也获得飞行能力，或有其他方法可以触及飞行目标。当个人载具停止运行或降落在地面上时、你处于危机状态时，或你正在通过防御行动掩护其他生物时，以上能力不生效。此外，如果这部个人载具上的任何生物在冲突中受到了风系、雷系或冰系伤害时，此模块的效果暂时停止，直到你的下一回合开始时。
    - **描述**：为了获得最鲜美的食材，不得不偶尔上天一趟
- **元素抗性**：
	- **特性**：雷元素抗性
	- **描述**：在驾驶这套战甲穿越几次云层后，终于长记性的帕尼时加装了这套避雷系统
- **强力锁定**：
	- **特性**：命中鉴定获得+2修正
	- **描述**：你为什么？当然是为了抓鸟
